This is accessible-openrb-338, the screen reader accessible fork of OpenRB-338:
  https://github.com/dengopaiv/accessible-openrb-338   (this fork)
  https://github.com/pingw33n/openrb-338               (OpenRB-338)

Screen reader mode. With Options > Screen Reader Mode on Automatic (the default), the app
turns the mode on while Windows reports a running screen reader, such as NVDA; on other
systems choose On. Every control then has a name and a spoken value, and these keys help:
  F1                 the list of keys (Help > Keyboard Shortcuts)
  F5                 play, or stop if playing
  F6, Shift+F6       the next or previous section
  Tab, Shift+Tab     the next or previous control
  F10, or Alt alone  the menu bar
The full guide is in the README on the fork's page above: "Using OpenRB-338 with a screen
reader". With the mode off, the app works as OpenRB-338 does.
